# Month 1, Part 2: Python Primitives & Computational Logic (Days 16–30)

## Core Learning Objectives
Transitioning from declarative database architecture (SQL) to procedural computational logic (Python). The primary objectives for this sprint are to:
* **Initialize Python Environments:** Utilize Kaggle interactive notebooks to execute code and manage versions via local Git commits.
* **Master Computational Foundations:** Understand primitive data types, variable assignment, arithmetic operations, and booleans.
* **Build Modular Logic:** Design reusable custom functions and implement conditional execution (`if`, `elif`, `else`).
* **Process Data Structures:** Iterate through lists and dictionaries using loops and list comprehensions to efficiently clean and manipulate datasets.
